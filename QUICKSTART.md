# Quick Start Guide - Cosmic Canvas

## 🚀 Get Running in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Application
```bash
npm start
```
The app will open at `http://localhost:3000` automatically.

### 3. Access the Platform
- Click **"Continue as Guest"**
- Select your **experience level** (Beginner, Intermediate, or Advanced)
- Click through to start exploring!

---

## 📱 Available Routes (After Login)

| URL | Feature |
|-----|---------|
| `/Explora` | Welcome page |
| `/Explora/home` | Main dashboard |
| `/Explora/worldmap` | NASA World Map |
| `/Explora/messier` | Messier objects explorer |
| `/Explora/starbirth` | Star birth regions |

---

## ✨ Instant Features (No Backend Needed)

✅ Welcome interface with smooth animations
✅ NASA satellite maps with MODIS data
✅ Interactive quizzes about Earth and space
✅ Messier catalog object explorer
✅ Star birth region interactive map
✅ Hubble deep-zoom image viewer
✅ Local guest account creation

---

## 🔌 Optional Features (Requires Backend)

These features need a running backend server on `http://localhost:5000`:

- User registration & login
- Save user progress
- User profiles & badges
- Permanent data storage
- Chatbot AI assistant
- Label/annotation storage

## 🛠️ Development

### Available Commands
```bash
npm start      # Start dev server
npm build      # Build for production
npm test       # Run tests
npm eject      # Eject from Create React App
```

### Project Structure
```
src/
├── components/       # Reusable UI components
├── pages/           # Page components for each router
├── App.js           # Main app router
└── index.js         # React entry point
```
